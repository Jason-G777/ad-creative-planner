# Brief 拆解与输入确认卡（brief-intake-card）

收到原始 Brief 后，在内部或第一步核心对齐时按此卡片快速结构化：

- **品牌与产品**：（品牌名 / 核心单品或系列 / 价格带 / 核心物理卖点）
- **核心商业目标**：（拉新 / 提频 / 客单升级 / 旺季冲量 / 口碑修复）
- **传播阶段与时间节点**：（官宣 / 上新 / 大促 / 节气 / 年度整合）
- **已知硬资产**：（已有代言人 / 已有 IP / 已有门店或渠道优势 / 既有历史心智）
- **刚性约束与雷区**：（预算量级 / 行业法规与功效禁区 / 艺人口径边界 / 历史已用过不可复用的旧口号）
- **目标人群初判**：（核心购买人群 vs 社交扩散人群 vs 线下承接人群）
- **核心信息缺口**：
  - *影响方向的必问项*：（仅列出不问就会跑偏的 1–3 个问题）
  - *可先做假设推进的项*：（标明工作假设，不阻塞首轮输出）
