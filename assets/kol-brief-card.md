# 达人种草 Brief 与内容角色分配卡（kol-brief-card）

用于规划达人矩阵或撰写单类达人执行 Brief：

- **本轮种草核心任务**：（对应大 Campaign 主线中的哪一环？解决用户哪一个具体顾虑？）
- **达人内容角色定位**：（破圈造热型 / 场景示范型 / 信任证明型 / 搜索口碑型）
- **目标平台与承接动作**：（小红书 / 抖音 / B 站 / 微博 + 搜索词/评论区引导/组件跳转）
- **必含生活场景与道具锚点**：（具体时间、地点、动作或自然对话切入点）
- **产品出场角色**：（情节转折点 / 记忆互动道具 / 实测验证工具，禁用硬背卖点）
- **核心传达信息（仅 1–2 点）**：（用达人自己的口语表达，不生硬念海报 Slogan）
- **合规与红线提示**：（禁用词、功效边界、艺人口径约束；缺真实体验数据时标明“以实测为准”）
