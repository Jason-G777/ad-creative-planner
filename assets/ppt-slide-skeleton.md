# “一页一结论” PPT / 飞书单页输出骨架（ppt-slide-skeleton）

当方向确认、进入逐页方案展开时，每页严格遵循以下结构，确保文字精炼、可直接贴进版面框格：

```markdown
## Page XX｜【页面结论标题：15–25 字，必须是一句有态度的判断，禁用目录词】

- **核心副标 / 一句话论点**：（1 句补足因果或转折，不超过 35 字）
- **页面主体模块**（按版面控制在 2–4 个并列模块，每块 1 个短标题 + 1–2 行极简说明）：
  - **模块 1**：...
  - **模块 2**：...
  - **模块 3**：...
- **视觉 / 画面 / 传播 Demo 示意**：（若为创意/事件页，附画面构想或 2 条模拟社媒发帖标题）
```
