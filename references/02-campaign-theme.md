# Campaign 主题与 Slogan

## 1. 从最终策略句出发，先校准品牌的声音

最终策略句确定要改变的购买选择；深层概念给出品牌对这件事的看法；主题文案让人记住并愿意复述这个看法。三者各有任务。

沿用动笔前根据品牌历史资产、价格带和品类属性定下的调性。提取一个辨得出的用词、动作或视觉习惯，作为本次表达的依据。品质克制的品牌可以靠一个准确的细节制造反差，亲和的品牌可以借一句熟悉的口头话打开话题。热点若要求品牌突然换一副腔调，就舍弃这个热点。

## 2. 概念挖深三阶梯

1. **表层平移｜起点**。写明谁在何时使用、看中什么卖点。若只得到一条场景陈述，继续追问这次选择对当事人意味着什么。
2. **情绪与关系张力｜下探**。抓住她想做却犹豫的一件事：哪两种愿望拉扯她？她在谁面前会改口、改选？用一个可信的动作或取舍说明，避免替一整类人编心事。
3. **观念重构／生活真相｜目标**。从品牌有资格发声的立场，挑明当事人早有感觉却少有人说透的事，让人重新理解一种日常状态或消费惯性。这个看法要能解释最终策略句，也能长出一支影片、一件公众可参与的事和一个社媒话题。

**常识与人话检验，一票否决。** 把概念原话念给普通人听。理想的回应是“这不就是我”。若第一反应是“有点怪”，尤其要查有没有曲解日常词义、硬拗因果或凭空造哲理。退回真实处境重写；自检时别把预想的回应当成真实反馈。

## 3. 用三圈交集凝练主题

概念站住后，再从**人群的情绪或动作、品牌能证明的产品或文化事实、艺人／IP 的辨识点**中选一个能承载概念的动作、物件或意象。没有合作方时，第三圈取品牌已有的表达资产。一句话说明三者如何共同说出那个看法；仅与某个物理细节或热门梗相像的联想，回到概念重选。

**品牌元素优先自然入句。** 主主题与 Slogan 优先使用品牌名、品牌核心字眼或独有的产品／文化符号，让人复述时顺带记住品牌。仅当名字过长或与语境冲突时，允许正文省名：把品牌名或独家资产放在表达开头，与只能由该品牌说出的正文一起呈现。避免生硬谐音和事后补标。

## 4. 交付前四项检验

1. **换品牌｜一票否决**。遮住 Logo，试换成同品类竞品，再试联名方单独署名。只要有一方能顺理成章接走，补强品牌专属依据或重写。
2. **五秒理解**。听一遍，受众能否说出这是谁的广告、大意是什么？若只记住梗、情绪或艺人，重新安排品牌元素。
3. **品牌证据**。指出文案中的哪个词、画面中的哪个动作来自品牌的具体资产，以及它怎样支撑概念。仅在句首换一个名字，无法证明归属。
4. **三类执行延展**。用同一概念想出 TVC 最值得看的一幕、事件中值得加入的动作、社交平台上值得复述的一句话。各自说得清品牌在其中的作用。

## 5. 首轮交付

默认推荐一个概念。交代深层概念与一句三圈推导，给出中英双语主主题、1–2 个同方向备选和四项检验的具体判断。正式 Slogan 默认中英双语，避开客户已停用的旧口号。备选在品牌调性内拉开节奏或语气，例如一句留白、一句短促；近义词替换不算备选。跨节点沿用母主题的核心动作或意象，各节点承担各自的任务。
