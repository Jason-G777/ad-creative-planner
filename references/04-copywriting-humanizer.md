# 分文体活人文案与去 AI 味指南（04-copywriting-humanizer）

## 1. 底层写作原则

1. **先用普通话说清判断，再做语言提炼**：逻辑没想透时，严禁用辞藻掩盖；先写一句大白话确认意思准不准，再按文体打磨语感。
2. **具象画面永远胜过抽象形容**：不要写“带来极致舒适体验与满满情绪价值”，要写出具体的时间、地点、动作、感官或生活细节。
3. **对仗与排比的清晰边界**：
   - **允许且鼓励紧凑对仗**：Campaign 主主题、Slogan、KV 主标、PPT 表格总结（如四字对仗、5+5 短句，追求高记忆度与版面齐整）。
   - **严禁机械排比**：PPT 正文说理、洞察阐述、社媒正文、口播稿与长文案，严禁连续三句字数相等的排比、伪深刻转折和空洞拔高。

### 去 AI 味 ≠ 去广告感染力

先圈住最有画面的一幕、最有立场的一句或最有反差的动作，再删空泛拔高和套话。保留态度锐度、网感幽默与提案节奏：值得停一拍的地方留白，笑点落下就收笔。若改完只剩谁负责、怎么核验、如何统计，回到现场，写出观众看到了什么、为什么会笑、为什么想转给朋友。

例如，“午后三点开展工位试吃活动”交代了安排；“下午三点，整层楼最响的一声，是第一只饼干罐掀盖。”给出了可听、可拍的开场。后一种写法用于创意示意，具体动作要由本案产品和场景支撑。

## 2. 六大广告文体分层标准（绝不混写）

| 文体类型 | 核心任务 | 写作标准与避坑要点 |
| :--- | :--- | :--- |
| **1. PPT / 飞书结论页** | 3 秒看懂这页讲什么 | 严格执行**“标题即结论”**（禁用“市场分析”“人群洞察”等目录标题）；副标与模块小字精炼到能直接贴进 PPT 框格，不溢出、不写大段散文 |
| **2. Campaign 主题 / KV 主标** | 一眼记住、有传播欲 | 追求短促有力、节奏明快；带产品物理事实或 IP/艺人专属锚点；不套任何品牌都能用的万能口号 |
| **3. 社媒嘴替 / 话题钩子** | 像真人在发帖、引发评论 | 抓第一反应情绪（惊叹、吐槽、玩梗、求问、自嘲），直给具体场景和槽点；不硬堆热词和满屏 Emoji，拒绝官号自嗨腔 |
| **4. 生活切片 / 情绪长文案（TVC / Manifesto）** | 制造真实代入感与余韵 | 从微小生活瞬间、大众口头禅或角色心理缝隙切入；长短句错落，关键句短句断句，点到为止留白，不强塞总结口号 |
| **5. 提案口播 / 艺人口播 ID** | 顺耳、好念、有呼吸感 | 先抛钩子/结论，再给具体动作或利益点，最后收口号召；删掉长定语和书面连接词，符合人嘴说话习惯 |
| **6. 达人 / 种草脚本文案** | 自然带出产品、建立信任 | 产品必须是情节需要、记忆动作或验证工具，不突然背卖点；无真实体验素材时，第一人称使用时长与效果标注“创意示意/待补充” |

## 3. 去 AI 味（Humanizer）强制质检门

所有消费者可见文案与提案正文，在逻辑与事实锁定后，必须过一遍静默质检：

### 高频 AI 病灶黑名单（命中即重写）
- **禁用空洞黑话**：`赋能、重塑、升维、破局、闭环、穿透、引领、致敬、匠心、全域引爆、价值跃升、心智占领（正文慎用）、构建生态、深度共振`
- **禁用固定 AI 句模**：
  - `不只是……更是……` / `这不仅是一次……更是一场……`
  - `从……切入，自然带出……`
  - `被看见、被理解、被记住`
  - `以……为抓手，打造……` / `在……的浪潮下`
- **警惕“假努力”描述**：不要把“真实、自然、共鸣、有温度、有网感”直接写进文案当卖点——那是你应该通过具体细节**做出来的效果**，不是用来贴标签的词。

### 改写四步法
1. **冻结不可改项**：锁定基础事实、数据、合规红线、品牌专属词、已确认方向与字数限制。
2. **定位 AI 簇**：整段扫出成簇出现的黑话、假大空拔高、连续三段式排比与同义词堆砌。
3. **具象重写（不删信息）**：把抽象名词换成具体的人、动作、物件和生活场景；保留广告该有的销售感、态度和修辞，不要改写成冷冰冰的说明书。
4. **朗读复检**：默读一遍，凡是念着拗口、喘不上气或听起来像年终总结的句子，全部删改。

## 4. Good vs Bad 实战对照（审美标尺）

### 对照 1：PPT 策略/洞察页标题
- **Bad（目录腔/空话）**：`消费者洞察：当代年轻人对性价比与情感价值的深度诉求`
- **Good（标题即结论）**：`从性价比（便宜就行）到心价比（便宜值得）：TA 们想要“便宜 + 放心 + 不被当傻子”`

### 对照 2：线下事件社媒传播钩子
- **Bad（AI 官方通稿腔）**：`某某品牌跨界联动重磅来袭，打造沉浸式体验空间，赋能年轻群体解锁多元互动新玩法！`
- **Good（活人路人视角）**：`24 小时营业的全家居然午夜熄灯了？？？门口站着一排柯南角色，说什么也要进去一探究竟`

### 对照 3：情绪/态度长文案（TVC / Manifesto）
- **Bad（空洞拔高+机械排比）**：`在充满不确定性的时代浪潮下，我们致敬每一位勇敢追梦的毕业生。这不仅是一杯茶，更是一份陪伴、一种力量、一次向未来出发的全新赋能。`
- **Good（具象意象+克制留白）**：`别着急，我们出发时，也不全然拥有勇气和力量。书本外的世界或许是一团迷雾，但走出城堡的那一刻，新的童话才真正开始。`

### 对照 4：产品卖点转译
- **Bad（干瘪形容）**：`精选优质糯米，带来极致软糯口感与满满好运寓意，满足消费者的美好期待。`
- **Good（动作+感官）**：`相比被动等好运，年轻人更想让好运追着自己跑——一口黏黏糯糯的汤圆，让好运主动黏上你。`
