# 广告策略核心指南（01-strategy-core）

## 1. 先纠偏：到底什么是广告策略？（必读）

广告策略**不是**商业目标（如“GMV 增长 30%”），**不是**正确但无用的口号（如“年轻化破圈、品效合一、全域种草”），**不是**创意金句，更**不是**媒介采买排期表。

**广告策略的本质**：在具体的**商业目标、行业/政策/舆情约束、以及消费者真实的决策阻力**之下，做出一个**有明确取舍的破局判断（从 Before 到 Now，我们靠什么赢、明确放弃什么）**。

| 常见 AI 假策略（严禁输出） | 真正的广告策略（目标标准） |
| :--- | :--- |
| 面向 Z 世代，打造年轻化品牌形象，提升声量与转化 | 现有“便宜”心智正反噬为“便宜但坑”，用户已从性价比转向“心价比”；本轮战略不是继续喊低价，而是通过“真诚靠谱”的强口碑背书，将心智升级为“便宜+放心” |
| 依托多平台矩阵，实现线上线下全域种草闭环 | 面对强监管行业禁止直接种草的刚性约束，放弃无效内卷，锁定仍可行的“内容场（长内容造知）→ 交互场（社交二传）→ 触达场（专业问询+线下终端）”三段接力 |
| 结合 IP 热度，推出联名包装与周边，刺激粉丝购买 | 竞品联名都停留在“贴图换壳”；我们发挥高频线下门店优势，把空间做成可逛可玩的沉浸体验场，兼顾死忠粉的“系列收集欲”与路人粉的“有梗好晒” |

## 2. 通用 0-to-1 策略核（进入创意前的必过门禁）

任何完整 Brief 必须先在内部跑通以下 8 步策略核，再往下推导创意：
1. **生意任务与增长来源**：增长从哪来（拉新、提频、客单升级、防流失还是口碑止血）？广告只负责推动哪一环？
2. **商业诊断（区分真假问题）**：区分商业症状（销量掉/好感降）、结构或政策约束（合规限制/渠道转移）、品牌心智问题（老旧/负面标签/无存在感）。
3. **消费者决策摩擦力**：在具体生活场景下，用户为什么不买、犹豫什么、吐槽什么？区分**可查事实**与**待验证假设**。
   - **核心顾虑正面拆解（不可绕行）**：逐一回应 Brief 点名的核心顾虑。写清消费者原来拿什么作比较、品牌希望她改用什么标准判断、哪项产品事实或体验撑得住这个新标准。比如“怕上火”背后若是把食品当作药补，可用一份开盖即食的夜宵甜品重建品类认知，避免暗示食用后的身体反应；面对“太贵”，可把单份价格放回她平时买精品奶茶或甜品的预算里比较，同价或更便宜须有依据。“智商税”要讲清钱花在哪、现场如何判断值不值；“嫌老气”要给她一个愿意亲自使用的新情境。仅列配料表或写“避开功效判断”，都没有答完策略题。
4. **旧规则 / 战略对手**：品类目前的同质化打法是什么？真正的竞争对手是谁（有时是竞品，有时是用户旧习惯或自身旧认知）？
5. **品牌破局杠杆**：品牌手里真正能解题的独家资产是什么（产品物理特性、渠道密度、历史信任、艺人/IP 契合点或服务能力）？
6. **战略取舍（Before → Now）**：用一句话说清本轮**争什么、以什么方式赢**，以及**明确不争什么、不说什么**。
   - 策略判断的最后一句必须点明“本轮明确不争什么 / 不说什么”。写出与所选方向真正竞争的人群、场景或主张，让这句话足以排除一种具体做法。
7. **改变机制**：哪类人在什么情境下，看到什么新证据/新体验后，会改变什么看法或动作？
8. **协同与验证**：内容、互动、搜索、电商、终端各自承担什么信息增量，用什么核心指标验证改变。

**六项自检**：归因（问题找对了吗）、抉择（有取舍吗）、品牌（换竞品还能用吗）、改变（能改变行为吗）、约束（踩合规/预算雷吗）、证据（事实与假设分清了吗）。

## 3. 五大高频项目类型的专属策略推导骨架

接到 Brief 后，先判断属于哪一类项目，调用对应骨架，不要拿同一套模板硬套：

### 类型 A：品牌 / 强监管行业年度传播策略（如医药、大健康、高客单耐消）
1. **环境与刚性约束扫描**：先识别政策新规（如禁止硬种草/功效词限制）、渠道迁移（如 O2O/即时零售增长）与用户决策链路变化（如主动搜索/AI 问询）。
2. **可行场域重构（Before → Now）**：不按惯性堆媒体，而是筛选“合规可行 + 匹配决策链路”的场域组合（如：内容场建认知 → 交互场做二传 → 触达场承接专业问询与线下终端）。
3. **按“传播角色 vs 购买角色”切分人群**：打破死板人口统计，区分三类人：
   - **造热/二传人群**：未必立刻买单，但负责社交扩散与内容玩梗；
   - **核心转化人群**：未必参与互动，但会刷到、会主动搜索并下单；
   - **刚需沉默人群**：线上触达弱，必须靠线下终端或身边场景承接。
4. **品类心智转译**：对敏感、严肃或老旧的品类功能，找到日常化、去羞耻感、低门槛的沟通语境（如将敏感滋补转译为“日常抗疲劳/提状态”）。

### 类型 B：明星 / 代言人营销策略
1. **心智缺口与负资产诊断**：明确品牌请明星究竟要补什么短板（拓新人群？拔高调性？还是对冲现有负面口碑？）。
2. **明确选人优先级标尺**：按当前目标排序（例如修复口碑时必须坚持**口碑 > 人设 > 受众**，而非唯流量论）。
3. **五维通用艺人评估**：从**专业作品与热度可持续性、大众路人缘与固有形象、粉丝画像与品牌 TA 重合度、商业价值与转化实绩、舆情/品行风险排查**五个维度论证“为什么非 TA 不可”。
4. **艺人原生资产拆解与四段激活**：拒绝把艺人当人形立牌，深挖艺人的名字梗、代表作、性格反差、常驻节目、粉丝称呼与巡演/行程节点，转化为：
   - **悬念与官宣造势**（预埋线索 → 双话题引爆）；
   - **粉丝情感激活**（用懂粉丝的宠粉行动和线下痛点解决，直接对冲品牌负印象）；
   - **创意内容交互**（把艺人特质变成用户可参与的玩法或二创素材）；
   - **平台/业务转化承接**（固定节点福利日、定制语音/周边、拉新裂变）。

### 类型 C：新品上市 / IP 联名策略
1. **破局竞品同质化**：先点出竞品联名或推新只停留在“换包装/堆卖点”的短板，找到我方差异化优势（如线下门店体验、产品物理形态、情绪符号）。
2. **双层人群洞察**：拆开**核心圈层/IP 死忠粉**（在意还原度、系列感、收集欲）与**泛路人盘**（在意有梗、实用、好晒、能引发生活共鸣），明确两拨人各用什么钩子打动。
3. **两层信息层级设计**：
   - **第一层（一眼买点）**：3 秒看懂“谁和谁联名了 / 新品是什么核心卖点”；
   - **第二层（深层痛点/精神）**：把产品卖点或 IP 内核与当下情绪及品牌长期主张焊在一起，沉淀品牌资产而非一次性收割。

### 类型 D：事件营销策略
1. **捕捉情绪裂缝或日常惯性**：找一个大众习以为常却能制造强烈反差的切片（如 24 小时便利店突然熄灯、城市地域文化符号、节气/毕业/春运集体情绪）。
2. **设定品牌的合理介入角色**：品牌不是硬凑热闹的赞助商，而是事件里的“发起人、解题者或情绪代理人”。
3. **构建双引擎事件结构**：
   - **新闻性奇观**（一眼反常识、自带标题党潜质，让媒体和路人忍不住拍）；
   - **参与/二创低门槛钩子**（普通人只需一个简单动作、一句暗号或一件道具就能卷入传播）。
4. **节奏与公关放大**：规划“悬念制造 → 现场/线上爆发 → 权威媒体或圈层二创定调 → 业务/门店引流”的完整接力。

### 类型 E：IMC 整合营销策略
1. **单核统领多节点**：先定一个贯穿全周期的核心品牌资产或情绪母题，避免每个节点各喊各的口号。
2. **阶段化角色分工**：按时间轴明确每个波段的唯一主任务（例如：造势官宣期打声量 → 新品/大促期做兴趣与种草 → 节气/大节点做仪式感与全民参与 → 旺季收口做礼赠与规模转化）。
3. **B/C 端与公私域协同**：明确长内容、短视频、直播、线下快闪、经销商/终端渠道各自承担的职能，确保每个触点都在放大同一个核心记忆点。

## 4. 默认交付节奏（两步法）

- **第一步（先交精炼核心）**：除非用户要求直接出全案，否则先输出 **1 份精炼的策略核心卡**（包含：核心诊断、Before → Now 战略取舍、目标人群分工、策略主线与 1–2 个方向建议），等待用户确认方向。
- **第二步（确认后详写）**：方向拍板后，再展开详细推导、分阶段规划、资源分工或 PPT 逐页内容。
