# 广告策略核心指南

## 1. 先找出广告能改变的选择

目标说明生意要增长多少；策略说明增长来自谁的哪一次选择，以及品牌凭什么赢得它。把销量表现、供货等经营条件与消费者的判断分开，找出广告能解释、产品或体验能证明的部分。

## 2. 从决策阻力到最终策略句

1. **增长与人群**。明确要拉新、提频还是挽回流失。区分谁使用、谁付钱、谁影响决定；同一人可兼任。找到真正需要改变的那一步。
2. **核心顾虑**。逐一回应 Brief 点名的顾虑。回到犹豫发生的时刻：当事人拿什么作比较？哪一种新的判断标准对她有意义？品牌用什么事实让她信？涉及价格，看同一笔预算的真实替代；涉及效果，守住证据边界。把待验证的解释标为假设。
3. **旧规则与品牌依据**。辨认消费者沿用的习惯、分类或比较对象。选一项足以改变判断的产品事实、文化资产或业务能力，并说明它怎样影响购买。
4. **战略取舍**。选定本轮争夺的人群、购买时刻或判断标准，用一句话明确放弃的战场或主张。取舍应足以帮客户排除一种原本合理的做法。
5. **最终策略句**。每次策略推导都收成 **1 句可独立上 PPT 封面的判断**，建议 15–28 字，作为下游概念、主题与事件的唯一总纲。拿掉页标题，仍应看得出目标人群原先怎么选、现在凭品牌哪项独特优势，会在哪笔生意上改选。挑最有区分度的词，不必把每个论据塞进一句话。
6. **改变机制与验证**。谁在何时遇到哪项证据，会改变什么判断或行动？据此确定内容、媒介与终端各自的任务，选能观察到该变化的指标。

策略句写完复读：换个品牌也成立，回查品牌依据；只讲把产品做成某个道具或开关，回到购买选择；靠多重转折和连续从句才说清、拖成超过 35 字的报告套话，删去铺垫重写。保留决定生意去向的那一层判断。

## 3. 按任务调整判断重点

- **品牌与受限传播**。分清事实、允许的主张与可用触点。核心顾虑仍须正面回应，选品牌能兑现的体验作证。
- **代言合作**。先说清品牌欠缺哪一种认知或信任，再看艺人的作品、公众形象、受众与合作权益。分别说明粉丝为什么愿意传播，普通购买者为什么愿意选择。
- **新品与 IP 联名**。讲清商品的新意、合作资产怎样改变使用或购买体验。核心受众认得的细节，也要让第一次接触的人看懂。
- **品牌事件**。找到日常惯例中值得改变的一刻。解释品牌能做什么、路人为什么想看、亲自加入之后会发生什么。
- **整合传播**。不同阶段共用同一句最终策略句。让每个触点增加一项新信息或减少一步购买阻力，按实际渠道和权益安排承接。

## 4. 首轮交付

单项策略先交诊断、取舍、人群分工、最终策略句与改变依据。完整 Brief 将这些判断放入第一模块，随后按入口的四模块交付。提交前核对归因、抉择、品牌、改变、约束与证据。
