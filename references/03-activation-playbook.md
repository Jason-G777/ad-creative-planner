# 活动创意与事件玩法指南（03-activation-playbook）

## 1. 好活动创意的两把硬标尺

任何线上/线下活动创意在进入细化前，必须同时满足两条标准：
1. **新闻性（反常识奇观）**：用一句话就能讲清“谁干了一件什么反常识但又完全合情合理的事”，路人一眼看懂品牌与联名/新品信息，忍不住掏手机拍。
2. **打卡与二创性（低门槛参与钩子）**：自带明确的拍照动作、互动暗号、物理彩蛋或可复制的社媒模板，让普通消费者 0 门槛卷入，而不是只能站在旁边当观众。

> **核心纪律**：严禁把“明星/IP/媒介资源清单”直接当成创意；必须明确区分“Brief 已有资源”和“方案新增的创意机制”，说清每个环节在解决什么问题。

### 常规终端陈列（POSM）≠ 创意事件

在冷柜门贴丝带、发试吃、印一张写着“我”的勺套，都属于常规门店促销及配套物料。它们能指路、介绍新品、方便试吃，却没有给路人一件值得专门拍下来讲给朋友听的事。严禁把这组动作当作核心创意事件提交。

提案先给出一个一眼反常识的视觉或行为奇观：路人隔着街看见哪一幕会掏手机？再说清走近后能参与什么，以及参与如何改变眼前的画面或结果。随案交 2–3 条模拟路人或博主的社媒发帖 Demo，标明创意示意。让每条写出一个可拍的瞬间或值得追问的细节；若帖子只能说“某店上新、可以领试吃”，回去重做事件。

## 2. 八大高频活动创意机制库（按需选 1 主机制 + 最多 1 辅机制）

1. **日常空间“剧本杀化”改造**
   - **本质**：把消费者高频路过的日常空间（门店、地铁、商圈、高铁站）改造成带角色、线索、暗号和任务的轻探索现场。
   - **抓手**：进门视觉引导 → 找特定角色/店员对暗号拿线索 → 分区寻找藏匿的产品“真凶/彩蛋” → 购买指定商品触发双倍积分或兑换周边。
2. **反常识“异常制造 → 全民解封”事件**
   - **本质**：预热期先故意制造一个打破日常惯性的悬念异常（如 24 小时门店午夜限时熄灯、代言人标志性笑容被“冻住”、神秘空位），再号召线上线下用户共同互动解锁真相。
   - **抓手**：悬念物料/夜光门贴/冰封海报 → 线下点击或线上滤镜助力解封 → 正式揭晓主题与直播/新品爆发。
3. **双人/多人协同物理机关**
   - **本质**：把“陪伴、友情、社交、碰杯”等抽象品牌精神做成必须靠物理动作触发的交互装置。
   - **抓手**：两人同时手拉手才能推开的互动门、双开门每次开合自动形成“隔空碰杯”的视觉、向两侧拉开就亮灯的交互礼盒、折角双屏隔空互动。
4. **城市地域文化与超级符号嫁接**
   - **本质**：借落地城市最具辨识度的地域符号与方言情绪（如牌桌文化、街头巡游、地标钟声），把常规发布会或快闪变成全城围观的在地事件。
   - **抓手**：把发布会搬进非传统场景（如牌桌上的发布会）+ 城市限定视觉装置 + 地域梗话题标签。
5. **产品卖点“仪式感道具化”**
   - **本质**：把产品物理特征（黏糯、温变、爆浆、便携等）转译为线下可玩、线上可拍的具象道具或出餐仪式。
   - **抓手**：遇热/遇冷显影的温变杯/碗、穿黏黏衣跳进海洋球池、扫码听专属语音/点歌、把常规出餐动作改造成带梗的“施法/开运仪式”。
6. **痛点场景“逆向温暖接管”**
   - **本质**：瞄准目标人群最疲惫、最狼狈或最需要仪式感的现实节点（演唱会散场、春运奔波、毕业离校、深夜加班），由品牌提供超预期的实体服务，直接反转刻板印象或拉满好感。
   - **抓手**：散场专属安心接送车队、穿特定服装（如学士服）招手即停的鲜花/产品专列、高铁站拥抱触发的派样广告牌。
7. **反差跨界与“虚拟身份下场营业”**
   - **本质**：宣布品牌“跨界转型”为某类奇趣机构（如好运贩卖公司），或请国民认知度极高的符号化角色下场担任一日店长、产品主理人或直播间主播，串联发布会、B 端订货会与 C 端店播。
8. **周边“金字塔分层”与二创社交货币设计**
   - **本质**：拒绝只印 Logo 的廉价赠品，把周边本身当成传播媒介，按人群动机做四层设计：
     - **底层（常规随单赠）**：低成本高频露出（贴纸、卡套、冰箱贴）；
     - **中层（核心粉收集向）**：强系列感、满足痛包/收集癖（随机角色徽章、亲签小卡、NFC 语音卡）；
     - **高层（大众玩梗/实用/好晒“小发明”）**：自带反差趣味和二创潜质（发光眼镜、异形手拎包、变温杯、披风毯），**每件必须预设 1 个低门槛二创拍法**；
     - **顶层（限量珍藏款）**：拉高客单或会员尊享兑换（主题灯箱、定制礼盒）。

## 3. 单个活动创意的 5 项必答交付要素

无论写线上事件还是线下快闪，完整细化时必须交代清以下 5 项，缺一不可：
1. **事件一句话钩子**：用一句自带新闻感的话说清核心看点。
2. **完整参与动线（Step 1 → Step N）**：用户走到现场/点开页面后，第一步看什么、第二步做什么动作/对什么暗号、第三步拿什么即时反馈。
3. **传播角度 Demo（必写）**：直接写出 **2–3 条模拟真实路人/博主发帖的标题或二创角度**（覆盖品牌自营/店员、核心粉丝、泛路人三类视角），反向验证事件是不是真的好拍、好晒、有槽点或爽点。
4. **平台与业务承接**：明确抖音/小红书话题或挑战赛、直播间引流、门店集点、扫码领券或电商跳转的具体接力点。
   - **存量终端资产轻复用（点面打通）**：Brief 已给数百个冷柜或全国网点时，核心事件首稿就要额外给出 **1 个成本极低、可复制到全部存量网点的轻互动彩蛋**。从样板事件挑一个观众最想玩的动作，借现有价签、杯套或瓶盖，让顾客在常去的店也能参与。比如样板放映“今日片尾”，各店就在原有价签上印同一个码，顾客扫码选一句当日片尾，下次来能选到新台词。交代清楚共用哪项现有物料、顾客做什么、再来一次有何新意；常规陈列只负责售卖，彩蛋负责把样板的记忆带到下一次购买。
5. **预算梯度模块（完整活动提案默认提供）**：
   - **S 档（轻量验证版）**：聚焦线上悬念 + 核心样板店/轻量互动物料 + 玩梗周边；
   - **M 档（标准整合版）**：核心城市主题快闪/巡游 + 门店联动 + 达人二创矩阵 + 电商/直播承接；
   - **L 档（全域放大版）**：多城地标大屏/无人机/专列事件 + 权威媒体 PR 定调 + 全渠道联名铺货。

## 4. 默认输出节奏

- **第一步（先交精炼核心）**：先输出核心创意机制、一句话事件钩子、3 步核心互动与 2 条传播角度 Demo，供用户拍板方向。
- **第二步（确认后详写）**：方向确认后，再补全完整动线、周边金字塔分层、传播节奏与 S/M/L 预算梯度。
