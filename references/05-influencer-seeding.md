# 达人种草与内容接力指南（05-influencer-seeding，初稿 v1）

> 注：本文件为 v1 通用实战初稿，待补充专属达人营销方案后可进一步细化平台筛选标准与脚本样例。

## 1. 达人种草的底层逻辑

达人营销不是“按粉丝体量拼凑采买名单”，而是**用不同内容身份的真实创作者，帮品牌把同一个核心卖点翻译成消费者听得懂、信得过、搜得到的生活语言**。

## 2. 按“内容角色”设计达人矩阵（而非只按体量）

规划达人矩阵时，必须先定义好 4 类内容角色及其各自承担的沟通任务：

| 内容角色 | 核心沟通任务 | 典型达人类型 | 衡量重点（定性） |
| :--- | :--- | :--- | :--- |
| **1. 破圈造热型（打开认知）** | 借强人设、脑洞或强话题把品牌/联名/事件带出圈，制造第一波围观 | 泛娱乐、搞笑剧情、Cos/变装、热点玩梗类头部/腰部 | 话题讨论度、评论区玩梗与二创跟风欲 |
| **2. 场景示范型（代入痛点）** | 把产品放进真实生活切片（熬夜加班、聚会、送礼、通勤、带娃），让用户一眼觉得“这不就是我” | 职场、生活 Vlog、美食、探店、宝妈/家居类腰部 | 场景真实度、收藏率与“求链接/求同款”评论 |
| **3. 信任证明型（打消顾虑）** | 用对比、实测、成分/工艺拆解或专业视角回答“为什么买你、凭什么值这个价” | 垂类测评、专业科普、成分党、行家/资深爱好者 | 信任背书强度、打消决策阻力的清晰度 |
| **4. 搜索口碑型（承接转化）** | 承接被种草后的主动搜索（如“XX 好吃吗/怎么选/避雷”），用高密度真实分享完成临门一脚 | KOC、精准细分场景素人、真实消费口碑笔记 | 搜索关键词占位、自然口碑密度与转化承接 |

## 3. 场景原生植入标准（拒绝硬背卖点）

设计达人内容方向或单条脚本时，必须满足以下 3 条：
1. **必有具象生活锚点**：每条方向至少写明 1 个具体生活动作、生活道具、场景细节或自然对话（例如“下班瘫在沙发拆快递”“牌局连输三把突然门铃响起”）。
2. **产品必须有“剧情职能”**：产品在内容里只能扮演三种角色之一——**情节转折点 / 记忆互动道具 / 问题验证工具**，绝不凭空切画面背诵 3 个卖点。
3. **区分“品牌文案”与“达人语境”**：Campaign 主题统领大方向，但达人内容必须说达人自己的人话，严禁把海报 Slogan 生硬塞进达人口播里。

## 4. 全域内容接力与平台适配

- **主线统一**：长内容/大事件建立认知 → 达人矩阵放大场景与二创 → 信息流/投流追击高潜人群 → 搜索词卡位、品牌直播间、电商详情页与线下门店承接转化。
- **平台角色按需推导**：小红书、抖音、B 站、微博、微信视频号各自承担什么任务，必须由**目标人群的真实决策链路**推导，不预设固定配比（如机械写死“达人:投流=6:4”或“固定 5 个标签”）。

## 5. 真实性与合规红线

- **严禁伪造口碑与数据**：没有真实产品测试素材时，达人第一人称的使用时长、具体体感和前后对比必须标注为`【创意示意，以真实体验为准】`，绝不编造虚假 UGC 评价或精准的 CPE/ROI 数字。
- **强监管品类红线**：涉及医药 OTC、保健食品、特证美妆等行业时，先核查 `references/07-market-and-guardrails.md`，禁止以达人种草名义违规宣称医疗或绝对化功效。
