# 八家代理商风格视角速查（06-agency-lenses）

> 使用纪律：结合客户经营模式、品牌阶段、核心问题与交付物，**选 1 个主参考视角**（必要时加 1 个职责明确的辅助视角）。只学其思考切入点与审美判断，不机械叠加、不模仿已有案例句式、不冒充代理商。

| 风格视角 | 核心基因 | 最适用的 Brief 场景 | 策略与创意切入偏好 |
| :--- | :--- | :--- | :--- |
| **观点叙事派（参考：群玉山）** | 品牌观念、社会议题、高观点、时代叙事 | 大品牌年度 Brand Campaign、重塑品牌价值观、重大节点/周年庆 | 从社会文化冲突切入，提炼高度概括的品牌观念，用克制而有力的公共文本建立品牌高度 |
| **青年网感派（参考：中好）** | 青年文化、社交趣味、脑洞反转、梗文化 | 面向年轻人的新品上市、B 站/小红书/抖音社交 Campaign、追求爆款扩散 | 善用幽默、反转、热梗与高能脑洞，把产品卖点转译成好笑、好晒的社交货币 |
| **情绪细腻派（参考：WMY）** | 叙事感、情绪价值、细腻共情、人际温情 | 节庆营销（春节/母亲节/毕业季）、情感类品牌 Campaign、建立情感粘性 | 钻进日常生活微小缝隙，通过具体的人际关系与心理细节触发自然共鸣 |
| **商业实效派（参考：BBDO）** | 商业逻辑严密、单一核心卖点、国际化质感 | 传统大厂/成熟品牌重点推新、兼顾品牌形象与规模转化 | 严格锚定商业目标，提炼单一且锋利的 Core Message，通过强视觉与强记忆点打透卖点 |
| **市井真诚派（参考：凡人广告）** | 接地气、烟火气、反套路、普通人视角 | 本地生活、性价比产品、电商大促、大众日常消费品 | 拒绝居高临下的说教，用真实、带点诙谐的普通人口吻讲清实实在在的好处 |
| **影视故事派（参考：胜加）** | 故事片叙事、长文案、文学性与画面感 | 品牌纪录片/微电影、匠心或多年沉淀的品牌故事 | 擅长层层递进的影视化叙事与耐读长文案，靠故事结构而非口号打动人 |
| **圈层玩梗派（参考：赞意）** | 粉丝经济、IP 联名、娱乐营销、种草裂变 | 明星代言官宣、动漫/影视 IP 联名、美妆/茶饮/快消社交引爆 | 极度熟悉圈层心理与社交平台二创机制，擅长把死忠粉收集欲与路人盘玩梗欲同时打通 |
| **全域整合派（参考：剧星）** | 大剧/大综内容整合、多触点接力、品效转化 | 大预算年度整合、大剧/短剧/综艺合作、直播与大促品效协同 | 注重高势能内容造知与社交二传、直播/电商/线下终端的连贯承接，追求曝光与生意双落地 |
